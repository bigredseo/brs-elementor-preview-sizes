# BRS Elementor Preview Sizes

A lightweight WordPress plugin that changes the visual preview widths used inside the Elementor editor without changing frontend responsive breakpoints.

## Default Preview Widths

- Mobile: 420px
- Tablet: 820px
- Desktop: Elementor default

The plugin only affects the Elementor editor preview canvas. It does not change Elementor breakpoint settings or frontend CSS.

## Requirements

- WordPress 6.5 or newer
- PHP 8.2 or newer
- Elementor
